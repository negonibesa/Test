# Прототип «Петровское СП» — описание реализации

Мобильное приложение спортивного сообщества «Петровское СП» (спортивный кластер в поселении). Всё сделано как **набор автономных статических HTML-прототипов**: каждый экран — самодостаточный файл (inline CSS + JS, без сборки, без зависимостей), связность через ссылки `href`, данные — JS-массивы в каждом файле. Единая брендовая дизайн-система и общая логика типов сущностей.

## Файлы (экраны)
- `index.html` — лончер-хаб: ссылки на все модули, легенда типов событий, бейджи «новый».
- `welcome-screen.html`, `splash-screen.html`, `splash-phone.html` — онбординг и сплэши.
- `home-athlete-brand.html` — главная спортсмена: баланс баллов, достижения, кольцо-прогресс ГТО, серия дней, лента событий, кнопка QR, табы (Главная / Расписание / Тренировки), лист событий, клубы.
- `events-system.html` — система событий: лента с фильтрами по типам, поиск, карточки с точкой типа и бейджем статуса, шит события с действиями по роли (организатор / участник / открытая запись), статусы.
- `create-event.html` — создание события: пошаговый мастер (Тип → детали → подтверждение → «Готово»). Типы: **Аренда площадки** (выбор зала/бассейна/корта + свободный слот), **Моя тренировка**, **С тренером** (выбор тренера + слот). Плюс шаблоны, приглашение людей, инвентарь/цены, итоговый экран с QR.
- `schedule-calendar.html` — **единый общий календарь**: месяц, точки-типы на днях, фильтры по типам и статусам, список событий дня, «последние», события ГТО, виды спорта.
- `qrscan.html` — сканер QR с камерой-оверлеем: выбор типа (мероприятие/тренировка/аренда), подтверждение входа.
- `trainings.html`, `training-active.html`, `training-report.html` — тренировки: план недели, активная тренировка (таймер/подходы), отчёт.
- `gto.html` — дневник ГТО: ступень, знак-цель (золото/серебро/бронза), нормативы со статусами.
- `gto-plan.html`, `gto-workout.html`, `gto-test.html`, `gto-result.html` — план подготовки, тренировка с таймером, тест норматива по шагам, результат с поздравлением.
- `points-ratings.html` — баллы и рейтинги (см. ниже).
- `notifications.html` — уведомления: лента, фильтры, «Прочитать всё», шит настроек.
- `search.html` — поиск по всему приложению (события, тренеры, клубы, спортсмены, площадки).
- `profile.html` — профиль спортсмена (пересобран по макету `profile-v2`): герой, статы, достижения, друзья, записи, цель ГТО, настройки, выход.

## Логика событий
- **Типы сущностей** (единая система везде): `me` — тренировка/индивидуальная, `trainer` — с тренером, `event` — глобальный ивент/соревнование, `club` — клубное событие, `rental` — аренда площадки, `gto` — ГТО.
- **Все типы падают в один общий календарь** (`schedule-calendar.html`) и в единую ленту — «любой тип события просто попадает в общее расписание».
- **Цветовое кодирование типов** (токены `--type-*`, одинаковые во всех файлах): тренировка `#2f9e54`, с тренером `#ffc93c`, ивент `#0b3d91`, клуб `#7ec8ff`, аренда `#4a6fa5`, ГТО `#c9a06b`.
- **Статусы** (`--st-*`): подтверждено (синий акцент), ожидает (жёлтый), открыта (тёмно-синий), завершено (серый), отменено (красный). Статусы и типы — независимые оси: карточка несёт точку типа + бейдж статуса.
- **Цвета назначаются программно**: `TYPES[x].token` → `style="--c: var(--type-*)"` — без хардкода; карточки/фильтры/точки/аватары читают `var(--c)`.
- Создание → отображение: мастер создания возвращает сущность того же типа/статуса, что потом видна в ленте и календаре.

## Баллы и рейтинги (`points-ratings.html`)
- Баланс баллов, уровни (Новичок 0 / Активный 1000 / Мастер 2500), серия дней (6), «награда до действия» — карточки задач: зал по QR +40, дома +20, соревнование 3-е место +50.
- Правила: участие в соревновании +50; места 1/2/3 = +100/+75/+50; серия 3/7/30 дней = +10/+25/+75; аренда +30.
- Журнал начислений со статусами: подтверждено / ожидает тренера / отклонено / система.
- **Античит**: в зале — динамический QR (обновление каждые 3 мин, привязка к устройству, временное окно); дома — подтверждение тренера, лимит 3 неподтверждённых в неделю; соревнования — судья по протоколу; нарушения — «отклонено» + списание баллов.
- Рейтинги по видам спорта: очки за места 1–8 = 100/85/75/65/55/45/35/25, участие +10; таблица лидеров, «моё место», результаты, сезон 2026.

## Уведомления · поиск · профиль
- `notifications.html`: фильтры-чипы (Все/События/Тренировки/Баллы/ГТО/Система) со счётчиками, группы «Сегодня/Ранее», нечитаемое с «Прочитать всё», действия на карточках (Принять/Отклонить приглашение), шит «Настройки уведомлений» с переключателями (открывается и по `#settings`). Персона: 12 уведомлений, 5 непрочитанных.
- `search.html`: строка поиска с очисткой, чипы категорий со счётчиками, старт-состояние (Недавние / Популярное сейчас / Категории), карточки-результаты по типу (событие со статус-бейджем, тренер со звёздами и ценой, клуб, спортсмен с бейджем ГТО, площадка «Свободно/Занят»), пустое состояние. Запрос матчится по `title/name/meta/place/kw/spec/role`. Коучи/спортсмены и голосовой поиск — тосты «в следующей итерации».
- `profile.html`: герой (Иван Петров, аватар 72px, чипы ГТО/место в регионе/серия 6 дней), статы (Тренировок 38 → `trainings.html`, Достижений 14/20 — прокрутка к блоку, Мой QR → `qrscan.html`), карточка «Моя цель · ГТО» (серебро, VII ступень, 60%) → `gto.html`, достижения (знак ГТО серебро, 3-е место Летний Кубок, 100 тренировок, золото — в процессе), друзья (24, 6 онлайн), «Мои записи» (силовая, аренда зала, Летний Кубок) → `schedule-calendar.html`, настройки аккаунта + выход (тосты «в полной версии»). Таб-бар: Главная / Расписание / Тренировки / Сообщество (заглушка) / Профиль (активен), бейдж Расписание 3.

## Дизайн-система (бренд)
- Светлая тема: фон `#eaf4ff`, поверхности белые/`#eef6ff`, акцент `#1a86e0`, «жёлтый = баллы» `#ffc93c`, success `#2bb066`, danger `#ff4d4d`.
- Шрифты: Oswald (заголовки), Inter (текст), JetBrains Mono (цифры). Радиусы 10/14/20, плавная анимация, mobile-first, адаптив.
- Все экраны согласованы по токенам; статус-токены и цвета сущностей едины по проекту (проведён аудит консистентности, найденное исправлено).
- **UI Kit (эталон)**: `Петровское-СП-_-UI-Kit-_эталон_-1.html` — «единственный источник истины» по дизайн-системе. Содержит токены (`--st-*`, `--type-*`, `--text-*`, `--yellow-on`), кнопки, инпуты, бейджи статусов (через `--c`), карточки, аватары (48/72/36, стек), шапку, таббар (fixed + blur + бейдж «3» + safe-area), иконки (69 шт., sprite `<use href="#ic-*">`), а также компоненты: чипы фильтров со счётчиками, шит, тост, прогресс-бар ГТО, строки-настройки, достижения `tone-gold/silver/accent/locked`. Шрифты — Google Fonts CSS2. Есть раздел «Конвенции» (data-od-id, sprite, `--c`, шрифты, заголовки 22/600). Дубликат `...-эталон_.html` удалён.

- Все экраны работают: навигация по ссылкам, JS-логика (переключение табов, фильтры, мастер создания, QR-подтверждения, счётчик баллов, уровни, таймеры ГТО, фильтры/настройки уведомлений, живой поиск).
