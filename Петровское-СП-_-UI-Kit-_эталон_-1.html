Конвенции (обязательны в экранах проекта)

  • data-od-id — каждый экран помечается data-od-id="<id>" на <body>, id из PROJECT_BRIEF.md.
  • Иконки — только SVG-sprite через <use href="#ic-*">, aria-hidden. Новые иконки добавляются в sprite, а не рисуются инлайном.
  • Цвет компонента — инлайново только через --c (см. бейджи статусов), сам hex — в :root.
  • Типы сущностей — --type-me, --type-trainer, --type-event, --type-club, --type-rental, --type-gto; статусы — --st-confirmed/pending/open/done/cancelled.
  • Шрифты — Oswald (заголовки и display, --font-display), Inter (текст, --font-base), JetBrains Mono (числа, --font-mono). Подключение — Google Fonts CSS2 в <head>.
  • Заголовки экранов — 22px / 600 / Oswald; крупные (онбординг) — 34px / 700.
  • Кнопка-капсула — 46px высота, радиус pill; первичная — акцент, вторичная — поверхность с рамкой.
  • Таббар — fixed, blur, padding снизу env(safe-area-inset-bottom), активная вкладка — акцент, бейдж уведомлений — --st-cancelled.
  • Радиусы — sm 10 / md 14 / lg 20; аватары — 48 (шапка), 72 (профиль), 36 (друзья), стек с нахлестом 10px.
